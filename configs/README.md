# Configuration files

This directory contains configuration files used to define paths, model settings, training parameters, and experiment metadata.

Configuration files help separate methodological decisions from executable code. This improves reproducibility and reduces the risk of hidden parameters inside notebooks.

Expected files include:

- `paths_example.yml`: example local and cloud paths.
- `model_config.yml`: model architecture parameters.
- `training_config.yml`: training, validation, and evaluation settings.
- `experiment_metadata.yml`: metadata for reproducible experiments.
