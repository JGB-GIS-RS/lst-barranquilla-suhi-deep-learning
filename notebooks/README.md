# Notebooks

This directory contains the computational notebooks used to reproduce the main methodological workflow of the study.

The notebooks are organized sequentially according to the processing chain:

1. Landsat data inventory and metadata organization.
2. Preprocessing, masking, LST extraction, and spectral index computation.
3. Tensor construction and patch extraction.
4. Baseline model implementation.
5. Deep learning model training.
6. Model evaluation and spatial diagnostics.
7. Map generation and hotspot analysis.

Large input datasets are not stored in this repository. Data access and reconstruction instructions are documented in the `data/README.md` file.
