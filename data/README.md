# Data

This directory documents the data sources and reconstruction workflow used in the study.

Large geospatial datasets are not stored in this GitHub repository. This includes:

- Landsat scenes.
- Raster stacks.
- Tensor datasets.
- Patch datasets.
- Trained model weights.
- Large GeoTIFF outputs.

The study uses Landsat Collection 2 Level-2 products to derive land surface temperature and spectral indices for the Barranquilla study area.

Data reconstruction instructions, including image selection criteria, preprocessing steps, masking procedures, and derived variables, will be documented in this directory.

A small sample dataset may be included only for testing the computational workflow.
