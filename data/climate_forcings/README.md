# Climate-radiative descriptors

This directory contains lightweight tabular and metadata products generated by
the NASA POWER processing workflow used in the Barranquilla LST/SUHI study.

The directory name `climate_forcings` is retained for consistency with the
notebooks and repository history. Scientifically, the variables stored here are
interpreted as annual regional climate-radiative descriptors associated with the
centroid of the modeling domain. They are not spatially distributed climate
fields at Landsat resolution.

## Purpose

The products in this directory document:

- the NASA POWER request and execution metadata;
- the geographic point used to query the model domain;
- daily source values and annual data availability;
- annual climate summaries;
- annual anomalies and interannual differences;
- the two descriptors retained for the final M5 configuration;
- diagnostic records associated with descriptor evaluation;
- the manifest of climate-related figures exported by Notebook 05.

## Temporal scope

```text
Daily and annual source period: 2013-2025
Interannual-delta period: 2014-2025
Model target-year records: 2016-2025
```

The year 2026 is excluded because it does not represent a complete annual period
comparable with the 2013-2025 products.

## NASA POWER variables

The workflow processes daily regional variables including:

- `T2M`: 2 m air temperature;
- `T2M_MAX`: maximum 2 m air temperature;
- `T2M_MIN`: minimum 2 m air temperature;
- `ALLSKY_SFC_SW_DWN`: all-sky surface shortwave downward radiation;
- `PRECTOTCORR`: corrected total precipitation;
- `RH2M`: 2 m relative humidity;
- `WS2M`: 2 m wind speed.

Annual summaries, anomalies, and interannual differences are derived from these
daily series for diagnostic and modeling purposes.

## Descriptors retained for M5

The final M5 configuration uses:

```text
delta_t2m_mean_Y_minus_Yminus1
delta_solar_radiation_mean_Y_minus_Yminus1
```

These variables represent the annual change between target year `Y` and the
immediately preceding year `Y-1`.

They are replicated spatially within model patches only to ensure tensor
compatibility. This operation does not imply intra-urban climate variability at
30 m resolution.

## Included files

### Source data and request metadata

- `05_nasa_power_daily_2013_2025.csv`  
  Processed daily NASA POWER values for the study-domain point.

- `05_nasa_power_daily_raw_2013_2025.json`  
  Raw NASA POWER response retained for traceability.

- `05_nasa_power_request_metadata.json`  
  Requested variables, temporal range, spatial point, and query parameters.

- `05_nasa_power_request_execution_metadata.json`  
  Execution-level metadata associated with the NASA POWER request.

- `05_domain_climate_point_wgs84.json`  
  WGS 84 coordinates of the point used to represent the modeling domain.

### Availability and annual summaries

- `05_nasa_power_year_availability_2013_2025.csv`
- `05_nasa_power_year_availability_2013_2025.json`  
  Annual availability and completeness diagnostics.

- `05_annual_climate_forcing_nasa_power_2013_2025.csv`  
  Annual regional climate and radiation summaries.

- `05_annual_climate_forcing_anomalies_2013_2025.csv`  
  Annual anomaly products derived from the regional series.

- `05_annual_climate_forcing_deltas_2014_2025.csv`  
  Interannual differences between consecutive years.

### Model inputs and diagnostics

- `05_model_climate_inputs_selected_m5b_2016_2025.csv`  
  Target-year table containing the two descriptors used by the final model.

- `05_climate_variable_selection_trace_2016_2025.csv`  
  Diagnostic record of the climate-variable evaluation workflow.

- `05_climate_forcing_integration_summary_2013_2025.json`  
  Summary of the climate-radiative integration stage.

- `05_climate_forcing_figures_manifest_2013_2025.csv`  
  Manifest of the diagnostic figures exported by Notebook 05.

## Naming note

The filename:

```text
05_model_climate_inputs_selected_m5b_2016_2025.csv
```

retains the historical internal identifier `m5b`. The public model label used in
the manuscript and repository documentation is:

```text
M5: T3-Climate ConvLSTM-SE U-Net
```

The historical filename is preserved to avoid breaking notebook paths and
execution records.

## Interpretation limits

The products in this directory support methodological traceability and
retrospective model conditioning.

They must not be interpreted as:

- pixel-level climate rasters;
- direct measurements of intra-urban microclimate;
- evidence of causal relationships between climate variables and LST;
- an autonomous forecast of future atmospheric conditions;
- a complete climate-model projection for 2035.

The file `05_climate_variable_selection_trace_2016_2025.csv` should be read as a
diagnostic record of the implemented workflow, not as independent causal or
prospective validation evidence.

## Storage policy

This directory is restricted to lightweight CSV and JSON products.

The following items are intentionally excluded:

- climate rasters;
- Landsat-derived full-resolution rasters;
- tensor and patch datasets;
- model checkpoints;
- prediction and residual maps;
- large temporary or intermediate products.
