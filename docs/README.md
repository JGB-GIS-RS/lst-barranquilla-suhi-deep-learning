# Documentation

This directory contains methodological documentation supporting the reproducibility of the study.

Expected documents include:

- `workflow.md`: complete methodological workflow.
- `data_sources.md`: satellite data sources and selection criteria.
- `preprocessing.md`: masking, calibration, LST extraction, and spectral index computation.
- `modeling.md`: model architectures, baselines, and training strategy.
- `reproducibility_notes.md`: computational requirements and limitations.
